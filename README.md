# StudentDev-Box DevOps Project

StudentDev-Box is a Docker-based CLI tool that helps computer science students create, run, and clean isolated development environments.

## Planned environments

- C++ development
- Python Data Science
- PostgreSQL

## Planned commands

```text
devbox start <course>
devbox stop <course>
devbox status
devbox clean <course>
